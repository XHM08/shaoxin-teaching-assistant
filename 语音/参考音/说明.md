# 参考音放这里（不进版本库，`.gitignore` 已挡）

「讲稿配音」用这里的一份录音去决定"用谁的声音说话"（GPT-SoVITS 拿它克隆音色）。

放两样东西，同名：

- `参考音.wav`：3～10 秒的清晰录音，一个人、无背景音、无音乐
- `参考音.txt`：第一行写那段录音念的是什么字（10～30 个字就够）

例如：

```
参考音.wav
参考音.txt   ← 第一行：各位同学好，今天我们学习分数的除法。
```

## 合规（这一条不能省）

声音是《知情同意书》里明确"不收"的一项。所以：

-  只有本人同意过的本人声音能用。老师的课用老师自己的声音，且同意书要补上一条并重新签之后才能用
-  学生的声音一律不碰
-  别人的声音（同行、公众人物、任何第三方）一律不碰

参考音只在本机放着、本机合成，不往任何外部服务上传。

安装与启动见上一级目录的 `说明.md`。
