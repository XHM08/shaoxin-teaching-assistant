工作台

电脑服务

不会用电脑也没关系 —— 用一句话说，或点下面的按钮。
只看不动的（看内存、看垃圾有多少）点一下就出结果； 要动手的（清临时文件、清回收站）会先把「会发生什么」摊开给你看， 你按 确认执行 才会真的做。

先说清楚一件事：Windows 没有可靠的「清理内存」操作 —— 那些号称清内存的软件 是把程序的工作集强行刷走，用起来反而更卡。真正管用的是 磁盘腾出空间（清临时文件）和 关掉不用的程序； 该关哪个，「谁最占内存」会告诉你，这一步请你自己关。 

        

        

          
        

      

    

  


  

    
    

      
环境配置

      

        

          检测这台电脑上有没有 Python / Node / Git / VS Code / WSL。
          检测只看不动；
          安装走 Windows 自带的 winget（微软官方包管理器），会先把「装什么、要多久、
          要不要授权」摊开给你看，你按 确认安装 才开始。
          


          WSL 不代劳：它需要管理员权限且装完要重启电脑，系统只给命令，请你自己执行。
          装完后本系统可能要关掉重开，才会检测到新装的东西。
