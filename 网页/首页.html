电脑服务

用一句话说，或点下面的按钮。
只看不动的（看内存、看垃圾有多少）点一下出结果； 要动手的（清临时文件、清回收站）先列出会发生什么，你按 确认执行 才真的做。

没有「清理内存」这个按钮。Windows 没有可靠的清内存操作，那些号称清内存的软件 会把程序的工作集强行刷走，用起来更卡。腾空间靠清临时文件，占用靠关掉不用的程序； 该关哪个，「谁最占内存」里有名字，关的动作请你来做。 

        

        

          
        

      

    

  


  

    
    

      
环境配置

      

        

          检测这台电脑上有没有 Python / Node / Git / VS Code / WSL。检测只看不动。
          安装走 Windows 自带的 winget（微软官方包管理器），先列出装什么、要多久、要不要授权，
          你按 确认安装 才开始。
          


          WSL 只给命令，不代你执行：它需要管理员权限，装完还要重启电脑。
          装完本系统要关掉重开，才能检测到新装的东西。

诊断草稿（只出主意，不动代码）

      

        

          把一条反馈和你点名要看的文件交给模型，产出定位、建议改动、要动哪几个文件、怎么验证、风险。

          上课一页页讲，学生按「我有问题」就暂停，答完再继续。
