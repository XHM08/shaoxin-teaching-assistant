# 「邵新」辅助教育系统 · 手机版

> 手机版和电脑版**用的是同一套数据和同一个服务**，只是换了一套按手机屏幕排的界面。
> 所以不要把它单独挪到别的位置去 —— 它靠相对路径找到「样本」文件夹。

## 怎么用

1. 双击 **`启动手机版.bat`**
2. 看清楚窗口里打印的那两行：

   ```
   本机打开： http://127.0.0.1:8765
   手机打开： http://192.168.1.100:8765/?t=a1b2c3d4
   ```

3. **手机连上和电脑同一个 Wi-Fi**，把「手机打开」那一整行（**连 `?t=` 后面那串一起**）
   输进手机浏览器。

用完就关掉那个黑窗口，服务就停了。

## 手机上能做什么

| 能 | 不能（要回电脑上做） |
|---|---|
| 学生用自己的编号提问 | 教师蒸馏 |
| 看学生档案（姓名、年级、记录） | 课件生成 / 联动教学 |
| 登记新学生、补填资料 | 环境配置 |
| 跟 AI 说话（创造模式） | 电脑服务（清内存、清垃圾那些） |
| 看模型用量与缓存命中 | 模型配置（换服务商） |

不能做的那几项不是没做，是**手机上本来就不好按**。以后要用再说。

## 安全上的三件事（别跳过）

**1. 那个 `?t=` 令牌是干什么的**

绑到局域网之后，同一个 Wi-Fi 上任何设备都能访问这个服务 —— 而这个服务里有
「电脑服务」和「执行命令」这种能力。所以**服务端**每次启动时都会随机生成一个令牌，
**只有带着它的地址才打得通**。关掉窗口再启动，令牌会换一个新的。

- 令牌**只打印在电脑的启动窗口里**，不会写到任何文件
- **别把带令牌的地址发到群里**，也别在公共 Wi-Fi（学校走廊、咖啡店）上开

**2. 本机（电脑自己）不需要令牌**

在电脑上打开 `http://127.0.0.1:8765` 还是和以前完全一样，令牌只对局域网来路生效。

**3. 学生数据仍然只存本机**

手机只是个遥控器：数据还是写在这台电脑的 `样本\学生数据\` 里，
姓名仍然只进 `对照表\姓名对照表.json`，不会因为用了手机就多发一份到别处。

## 手机打不开，按这个顺序查

1. **手机和电脑是不是同一个 Wi-Fi**
   手机流量要关掉；有些校园网把设备隔离开（"AP 隔离"），那种网下手机连不到电脑。

2. **Windows 防火墙拦了** —— 这是最常见的原因，但**先看下面这个坑，照旧写法做会白折腾半天**

   Windows 把你连的每个网络分别标成「专用网络」或「公用网络」，而防火墙规则是
   **按这个标签各管各的**：只勾了「专用」的规则，在标成「公用」的网络上一律不生效。

   ⚠ **本机现在的 Wi-Fi 就是「公用」**（2026-09 实测：`WLAN` → `Public`）。
   所以照「只勾专用、公用不要勾」做，手机**永远连不上**。

   **先确认你现在是哪种：**
   - 设置 → 网络和 Internet → WLAN → 点你连的那个 Wi-Fi → 看「网络配置文件类型」
   - 或者按 `Win+R` 输 `powershell`，粘这一行回车：
     `Get-NetConnectionProfile | Select InterfaceAlias,Name,NetworkCategory`

   然后二选一：

   **(A) 推荐：把自己家的 Wi-Fi 改成「专用网络」，再只勾「专用」**
   1. 设置 → 网络和 Internet → WLAN → 点你连的那个 Wi-Fi → 「网络配置文件类型」改成**专用**
   2. 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
      → 找到 **Python**，勾上「专用」那一列

   这样在公共 Wi-Fi（走廊、咖啡店）上仍然拦着，最安全。

   **(B) 实在改不了网络类型（比如校园网不让改）：那就「专用」「公用」两列都勾**
   - 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
     → 找到 **Python**，「专用」和「公用」两列都勾上
   - ⚠ 代价：以后在**任何**公用 Wi-Fi 上，别人也可能连到你这一台 ——
     所以用完就把「公用」那列取消，或者只在需要给学生用时才开这个服务

   找不到 Python 就在列表里点「更改设置」→「允许其他应用」→ 浏览到
   Python 安装目录里的 `python.exe`（装的时候看到过那个路径）。
   ⚠ 列表里以 `WindowsApps` 结尾的那个**不要选** —— 那是应用商店的空壳，选它照样连不上。

3. **地址输错了**
   `?t=` 后面那串每次启动都不一样，要用**当前这个窗口**里打印的。

4. **手机浏览器自动跳到了搜索**
   有些浏览器会把地址当关键词搜。把整行**粘贴**进去，别手打。

## 它和「样本」的关系

- 服务端代码、网页、数据**全都还在 `桌面\样本\`**，这里没有副本
  （不留副本是故意的：留了就会出现"改了一边忘了另一边"）
- 手机版界面本身是 `样本\网页\手机.html`
- 电脑上打开 `http://127.0.0.1:8765` 还是电脑版；
  用手机打开根地址会自动给手机版，也可以直接输 `/网页/手机.html`
