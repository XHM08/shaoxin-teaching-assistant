# 参考资料存放处

XR: C

公开的参考资料放这里：省/市教研文件、课标与教材、别人公开发表的教案、查新用到的论文与报道。

它和 `材料/` 是两种东西，别混：

| | `材料/` | `参考资料/` |
|---|---|---|
| 是谁的 | 合作老师本人的材料 | 公开资料 |
| 用来干什么 | 蒸馏成技能包 | 查口径、当参照、对齐术语 |
| 能不能直接下锅 | 能 | 不能。蒸馏要的是这位老师的讲法 |

> 为什么单独放一栏：公开教案里有"讲什么、按什么顺序讲"，但没有这位老师面对
> 具体错法时怎么纠、也没有他的口语措辞。拿它蒸馏出来的东西，不是这位老师的技能包。
> 界面上把这句话写在那一栏里，就是为了防止这一点。

## 注意

- 可能含正式出版教材（有版权）：这个目录不进版本库（见 `.gitignore`），也不要放进任何公开仓库
- 格式不限：`.docx` / `.pdf` / `.pptx` / `.xlsx` / `.txt` / `.md` / `.html` / 图片都能列出来、都能读
- 子文件夹会递归列出（按主题分文件夹放没问题）
- 引用时写明来源与获取日期，不要整段照搬
- 图片与扫描版 PDF 会走本机 OCR，有错字，引用前对照原文

## 放在别处也行

默认是 `参考资料/`。要把这一栏指向已经存在的文件夹（不搬文件、不留两份副本），
改 `配置.json`：

```
"目录": { "参考资料": "D:/某个文件夹/收集的文件" }
```

路径写绝对路径就按绝对路径取，写相对路径就按项目根目录取。
