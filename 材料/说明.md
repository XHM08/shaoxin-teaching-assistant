# 教师材料存放处

XR: C

真实教师材料放这里（教案、访谈转写、批改痕迹的文字）。

这个目录的内容不进版本库（见根目录 `.gitignore`）。原因：材料属于教师本人，且可能含学生信息。

## 命名建议

`教师A-教案-2026春.docx`

> 用了 `教师A` 这种代号而不是真实姓名，是为了让文件名本身也不含可识别信息。
> 真实姓名与代号的对照关系，另存于项目组本地，不进本目录、不进版本库。

## 能放什么

常见格式直接放就行，不用先转成文本。系统只把里面的文字读出来（供蒸馏用），不改动原文件。

- **子文件夹也认**：把同一章的材料放进一个子文件夹（例如 `水循环/`），系统会一并列出，
  名字显示成 `水循环/教案.docx`，蒸馏时也选得到。
  （这一点以前只认顶层文件：结果是"配图用得上、蒸馏里却找不到"，2026-10-05 已统一）
- **文档**：`.docx`（Word）、`.pptx`（PPT）、`.xlsx`（Excel）、`.pdf`
- **文本与表格**：`.txt`、`.md`、`.csv`、`.json`
- **网页**：`.html`、`.htm`
- **图片**：`.png`、`.jpg`、`.jpeg`、`.bmp`、`.gif`、`.tif`、`.webp`

## 要留意的几件事

- 照片直接放，由本机 OCR 转成文字。字要清楚、方向要正
- 扫描版的 PDF（整页是图、没有文字层）会自动逐页做本机 OCR，一本最多转前 50 页
- **老格式 `.doc` / `.xls` / `.ppt`**：程序读不了，先用 WPS 或 Word 打开「另存为」新格式
- 单份材料不要超过 64 MB，太大请先拆开
- 中文 Windows 存出来的 `.txt` 多半是 GBK 编码，这个也认
- 录音先在本机转写成文字，再放进来（原始录音不发送给任何服务商）
- 材料进入本项目前，需先取得教师本人签署的《知情同意书》

## 和「参考资料」的区别

`参考资料/`（或它在 `配置.json` 里指到的别处）放的是公开资料：省教研文件、教材、
别人发表的教案。那些只能当参照，不能当蒸馏原料。蒸馏要的是这位老师本人的讲法。

这一栏在网页的「本地知识库」里单独列出，就是怕两者混起来。

## 关于 OCR

用的是 Windows 自带的识别引擎：不联网、不装东西、图不出这台电脑。

代价是会有错字。所以：

- 转录出来的文字开头会标一句「本机 OCR 转写，可能有错字」，提醒你它不是原文
- 蒸馏出的技能包，要请老师过一遍再定稿。错字会一路传进技能包
